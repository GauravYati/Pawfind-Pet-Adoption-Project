# PawFind Workspace

This workspace is split into two separate projects.

- `pawfind-mern`: MongoDB, Express, React, and Node.js application
- `pawfind-playwright`: Playwright UI/API automation, Page Object Models, and screenshot tooling

## Run The App

```bash
cd pawfind-mern
npm.cmd run install-all
npm.cmd run dev
```

## Run Tests

```bash
cd pawfind-playwright
npm.cmd install
npm.cmd run test:e2e
```
